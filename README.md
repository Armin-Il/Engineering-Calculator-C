# 🧮 Advanced Engineering Calculator in C

A modular command-line engineering calculator developed in **C**, designed to perform mathematical, statistical, matrix, unit-conversion, and engineering-oriented computations.

The project was developed as a hands-on implementation of C programming concepts, numerical computation, file I/O, matrix operations, and terminal-based visualization.

---

## ✨ Features

### 🧮 Mathematical Operations

- Basic arithmetic operations
- Trigonometric functions
- Powers and roots
- Logarithmic and exponential operations
- Degree / Radian angle modes

### 📐 Matrix Operations

- Matrix calculations
- Linear algebra operations
- Interactive matrix input and processing

### 📊 Function Plotting

- ASCII-based mathematical function visualization
- Terminal-based data plotting

### 🔄 Unit Conversion

- Temperature conversion
- Weight conversion
- Distance conversion

### 💾 Memory & File I/O

- Save calculation history
- Retrieve previous calculations
- Persistent storage using `calculator_memory.txt`

### 🖥️ Interactive CLI

- Menu-driven interface
- Interactive operation selection
- Input validation
- User-friendly terminal interface
