# Advanced Engineering Calculator in C

A comprehensive, modular engineering calculator implemented in C. Designed for high-performance mathematical computations, memory operations, and statistical calculations.

## Key Features
* **Basic & Advanced Math:** Supports arithmetic, trigonometry, powers, and logarithmic operations.
* **Memory Management:** Saves and retrieves calculation history using file I/O (`calculator_memory.txt`).
* **Unit Conversions:** Temperature, weight, and distance converters built-in.
* **Interactive CLI Interface:** Clean, user-friendly command-line interface with angle mode switching (Degrees/Radians).
* **Matrix Operations:** Built-in matrix calculations and linear algebra functions.
* **Function Plotting:** ASCII/Terminal-based visualization for mathematical functions and data plots.

## How to Compile & Run
```bash
gcc main.c -o calculator -lm
./calculator
